# ETF Insight

네이버 금융의 [ETF 목록 API](https://finance.naver.com/api/sise/etfItemList.nhn)를 이용해 국내 상장 ETF를 조회하고 분석하는 로컬 HTML 대시보드입니다.

## 실행

Node.js 18 이상에서 추가 패키지 설치 없이 실행할 수 있습니다.

```powershell
node server.js
```

브라우저에서 `http://127.0.0.1:8000`을 엽니다. 포트를 바꾸려면 `PORT` 환경 변수를 설정합니다. GitHub Pages 같은 정적 호스팅에서는 네이버 금융의 JSONP 응답을 직접 읽습니다.

## 기능

- ETF 목록 60초 자동 갱신 및 수동 새로고침
- 운용사, 투자시장, 상품유형, 추정 순자산총액 구간별 필터와 검색
- 분포 그래프, 정렬 가능한 목록, 페이지 이동, 필터 결과 CSV 다운로드
- 데이터 원천 연결 오류 시 마지막으로 받은 목록 표시

## 데이터 기준

네이버 응답의 `marketSum`은 **시가총액(억원)**이며 순자산총액이 아닙니다. 화면의 **추정 순자산총액(억원)**은 `marketSum × nav ÷ nowVal`로 계산합니다. 상장좌수를 `시가총액 ÷ 현재가`로 추정한 값이므로 공시된 확정 순자산총액과 차이가 날 수 있습니다. NAV나 현재가가 없으면 추정값은 표시하지 않습니다.

API에 운용사명이 없어 종목명 앞의 브랜드를 운용사로 연결합니다. 브랜드 연결은 [ETFro의 운용사별 목록](https://etfro.com/provider/)을 참고했습니다. 투자시장은 네이버의 `etfTabCode`와 상품명의 국가 단어로, 상품유형은 `etfTabCode`와 상품명 키워드로 분류합니다. 원천 API가 제공하지 않는 분류이므로 일부 종목은 `기타·미확인` 또는 `기타`로 표시될 수 있습니다.

로컬 서버는 네이버 금융의 EUC-KR 응답을 UTF-8 JSON으로 변환해 브라우저에 전달합니다. GitHub Pages에서는 API가 제공하는 JSONP 콜백을 사용합니다. 페이지는 60초마다 조회하지만 네이버 금융 자체의 시세 갱신 주기를 앞당기지는 않습니다. 네이버가 JSONP 제공을 중단하면 정적 배포판의 실시간 조회는 중단될 수 있습니다.
